# Proyecto Calculadora Cliente
## Descripción
Este proyecto consiste en el desarrollo de una calculadora utilizando HTML, CSS y JavaScript. Permite realizar diferentes operaciones matemáticas sin recargar la página. 

## Funcionalidades
La calculadora permite realizar las siguientes operaciones: 
- Suma
- Resta
- Multiplicación
- División
- Potencia
- Resto

También permite: 
- Introducir números negativos y decimales
- Validar los datos introducidos
- Mostrar mensajes de error cuando sea necesario
- Limpiar los campos y restablecer la calculadora

## Cómo utilizar la calculadora
1. Introducir el primer número
2. Introducir el segundo número
3. Seleccionar la operación que se quiere realizar
4. Pulsar el botón "Calcular" o la tecla Intro desde cualquiera de los campos numéricos
5. El resultado aparecerá debajo del formulario

Para borrar los campos y restablecer la calculadora, se deberá pulsar el botón "Limpiar"

## Tecnologías utilizadas
- HTML: estructura de la calculadora
- CSS: diseño y estilos de la interfaz
- JavaScript: operaciones matemáticas, validaciones y funcionamiento de la calculadora.
